CAPTOR

Text-encoder-free grounding by counting caption co-occurrence over a frozen encoder's visual words

Elad Yoshai  and  Natan T. Shaked

Tel Aviv University

Paper Code Try it in Colab Pretrained tables

Summary

Grounding a text query in an image needs a matrix that scores every term against every patch. Vision-language models compute it with an aligned text encoder, which many image encoders, such as pathology models trained on slides alone, do not have. CAPTOR estimates the matrix without a text encoder. It clusters a frozen image encoder's patch tokens into visual words and describes each captioned image by the share of its patches in each word. A term's signature is the standardized difference of those shares between images whose captions mention the term and the rest. The matrix then factorizes into a term-by-word table and a query-independent image factor, so an image is encoded once and a new term adds one row to the table. On COCO, scored on the cells one object owns, CAPTOR reaches 0.565 mIoU, and on held-out breast-cancer patients 0.497 mIoU. Read through CAPTOR, UNI, an encoder trained on slides alone with no text tower, can be queried in words.

Use it

pip install git+https://github.com/EladYoshai/captor.git

from captor import CAPTOR
model = CAPTOR.from_pretrained("coco_dinov2reg_k640")      # or "pathcap_conch_k80"
seg = model.segment("photo.jpg", ["cat", "dog", "bed"])
seg.labels, seg.scores, seg.shares()
